# kunstruk wallpapers — sources

Original artwork.

## Plates drawn by code

`wall_punkt`, `wall_linie`, `wall_flaeche`, `wall_schrift`, `wall_spannung`, `wall_ruhe`: drawn by `make_plates.py kunstruk`
(Pillow, 2x then downsampled, fixed paper grain), set in Jost (OFL, `../fonts/`). Point, line and plane in the
spirit of the Bauhaus teaching; the left third of every plate stays empty for the clock, the title and the player.
Re-run `python3 make_plates.py kunstruk` after any change: the output is the same file for the same code.
